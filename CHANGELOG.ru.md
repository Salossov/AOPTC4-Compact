# История изменений

## 0.8.0 — 2026-10-30

- ID загрузчика NeoForge: `thaumcraft_compact`; namespace контента `thaumcraft_viewers`, существующие конфиги и обнаружение интеграций сохранены.

- Автоматическая сборка зависимостей AOP из исходников в CI с проверкой ревизий и хешей JAR, без ручных переменных архива.

- Интеграции просмотрщиков рецептов и HUD для Thaumic Energistics, включая арканный крафт и устройства эссенции; обновлены AOP UI и метаданные зависимостей.
- Minecraft 1.21.1, NeoForge 21.1.166, Java 21. Локальные сборки и приёмка отделены от публикации.
- Минимальная поддерживаемая NeoForge: 21.1.166. Интеграция AE2 собирается с 19.0.24.
